# 🎵 BeatStream - Visualizer Music Player

A sleek, modern web-based audio player featuring a real-time frequency visualizer, playlist management, shuffle/repeat modes, and smooth marquee text effects. Built with vanilla HTML5, CSS3, and JavaScript (Web Audio API).

---

## ✨ Features

- 🎧 **Real-time Audio Visualizer**: Dynamic HTML5 Canvas bar visualizer powered by the Web Audio API (`AudioContext` & `AnalyserNode`).
- 📜 **Playlist Management**: Upload multiple local audio files at once with sequential playback and active song indicators.
- 🔀 **Playback Modes**: 
  - **Shuffle**: Play tracks in random order.
  - **Repeat Options**: Repeat Off, Repeat All, or Repeat One track continuously.
- 🎛️ **Full Playback Controls**: Play, Pause, Next, Previous, Dynamic Progress Bar with time tracking, and Volume Control.
- 🎨 **Modern Responsive UI**: Cyberpunk-inspired frosted glass UI (`backdrop-filter`) with responsive design for mobile and desktop screens.

## 🚀 How to Run

1. **Clone or Download** this repository.
2. Open `index.html` directly in any modern web browser (Google Chrome, Microsoft Edge, Firefox, or Safari).
3. Click on the **"Add Songs"** button to select `.mp3` or other supported audio files from your computer.
4. Enjoy the music along with the dynamic visualizer!
